# PRIZM

A collection of ROS2 (Jazzy) packages being developed for the PRIZM project.

There's an accompanying docker image which can be found [here](https://github.com/RealRobotics/PRIZM_docker).

## Content Summary

* [prizm_dynamixel](prizm_dynamixel) Contains a driver to run $n$ servos and $n$ motors from a dynamixel U2D2 driver board.
* [prizm_interfaces](prizm_interfaces) Contains a collection of interfaces, currently only used by the dynamixel driver.
